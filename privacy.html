Privacy Policy

Last updated: 2026-11-25

This policy describes how gws-cli handles data. gws-cli is a personal command-line tool used only by its developer.

Data accessed

With the user's consent, gws-cli requests read and write access to Google Workspace services of the signed-in account: Google Drive, Google Docs, Google Sheets, Google Slides, Gmail, Google Calendar, and Google Tasks. It also requests access to Google Cloud and Pub/Sub resources of that account. It reads and changes files, documents, spreadsheets, presentations, email messages, calendar events, tasks, and related metadata.

How data is used

Data is used only on the developer's own computer, and only when the developer runs a command, to view and work with the developer's own data. It is not used for advertising or profiling.

Storage

gws-cli does not send Google user data to any server other than Google. OAuth tokens are stored encrypted on the local computer. Data that the developer chooses to save stays on that computer.

Sharing

Google user data is not sold, shared with, or transferred to any third party.

Limited Use

gws-cli's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Questions about this policy can be sent through GitHub.
