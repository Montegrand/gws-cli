Privacy Policy

Last updated: 2026-11-25

This policy describes how gws-cli handles data. gws-cli is a personal command-line tool used only by its developer.

Data accessed

With the user's consent, gws-cli requests read-only access to Google Drive and Google Sheets. It reads file metadata, file contents, and spreadsheet values.

How data is used

Data is used only on the developer's own computer to view and work with the developer's own files. It is not used for advertising or profiling.

Storage

gws-cli does not send Google user data to any server other than Google. OAuth tokens are stored encrypted on the local computer. Files that the developer chooses to save stay on that computer.

Sharing

Google user data is not sold, shared with, or transferred to any third party.

Limited Use

gws-cli's use and transfer of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access

Access can be revoked at any time from Google Account permissions.

Contact

Questions about this policy can be sent through GitHub.
